# サバヨミ

文章をサッと読んで、パッと判断する力を気楽に鍛えるゲームです。
速さだけでも正確さだけでもなく、両方をかけ合わせた **実効読速（字/分）** で成長を測ります。

## モード

| モード | 内容 |
|---|---|
| 仕分けラッシュ | 40秒間、短い文を左右スワイプで仕分ける。速く読むほど高得点、ミスは−3秒（事実/意見、今日やる/あとで、ただの情報/売り込み、合ってる/おかしい。1回のプレイはお題1つ） |
| 見出しセレクト | 300字ほどの文章を読み、合う見出しを3択から選ぶ（全5問） |

## スコア

- **実効読速** = 読む速さ（字/分、上限3000）×「勘で当たる分」を差し引いた正確さの2乗
  - 2択で正答率50%なら0、95%なら0.81倍。適当な連打では伸びない
- 仕分けの得点 = 基本点（文の長さ）× 読む速さ（500字/分で1.0、0.5〜1.5）× むずかしさ（1 or 1.5）× コンボ
- ランク: 見習い → 読み手(250) → 速読家(450) → 情報さばき師(700) → サバ読みマスター(1000)
- 記録は端末の localStorage に保存（ログイン不要）

## 開発

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # スコア計算と問題データのテスト
npm run lint     # 型チェック
npm run build    # out/ に静的サイトを出力（どこでもホスティング可）
```

スマホのホーム画面に追加すると、アプリのように全画面で遊べます（PWA）。

## 問題データ

- `data/sort.json`（仕分けカード80枚。level 1=ふつう、2=むずかしい）と `data/headline.json`（見出し問題12問）。すべて架空の文章です
- `npm test` で、ID重複・答えの偏り・字数などを検査します

### AI で問題を増やす

```bash
ANTHROPIC_API_KEY=... npm run generate -- sort fact 10        # お題: fact / urgent / ad / logic
ANTHROPIC_API_KEY=... npm run generate -- headline 社内メール 5
```

Claude で問題を生成し、正解を隠して別の呼び出しで解き直し、答えが一致した問題だけを `data/generated/` に書き出します。
人が目を通してから、ID を付けて `data/*.json` に追加してください。
